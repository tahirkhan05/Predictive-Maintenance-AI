1. Introduction

Predictive Maintenance (PdM) is a data-driven equipment management strategy that evaluates the condition of industrial machinery by analyzing operating parameters and sensor telemetry. Unlike reactive maintenance (repairing equipment only after failure) or scheduled preventative maintenance (servicing machines on arbitrary calendar intervals), predictive maintenance uses machine learning algorithms to anticipate mechanical breakdowns before they disrupt operations.

2. Problem Statement

Modern manufacturing facilities rely heavily on high-speed rotational milling machines. Unplanned machine seizures, tool fractures, and thermal dissipation failures cause sudden factory line standstills, scrapped workpieces, high repair costs, and safety hazards.

The primary objective of this project is to build an intelligent binary classification system that predicts whether an industrial machine is likely to fail (1 = Machine Failure, 0 = Normal Operation) based on its operating sensor parameters, while prioritizing high recall for critical failure detection and maintaining a low false-alarm rate.

3. Why This Project Was Made

  • Reducing Unplanned Downtime: Advance failure warnings allow maintenance crews to service equipment during scheduled changeovers rather than during active production runs.
  • Minimizing Repair & Maintenance Costs: Catching tool wear and torque overstrain early prevents catastrophic secondary damage to expensive spindles, drives, and gearboxes.
  • Preventing Scrap & Material Losses: Machine failures mid-cut ruin expensive raw stock and workpieces.
  • Enhancing Workplace Safety: Early detection eliminates catastrophic tool fractures that can eject high-speed metal fragments.

4. Dataset

This project uses the official AI4I 2020 Predictive Maintenance Dataset from the UCI Machine Learning Repository.

  • Source Link: UCI Machine Learning Repository — AI4I 2020
  • Nature: Synthetic dataset reflecting realistic milling machine telemetry.
  • Observations: 10,000 records.
  • Missing Values: 0 (fully verified clean dataset).
  • Target Variable: Machine failure (Binary: 0 = Normal [96.61%], 1 = Failure [3.39%]).
  • Class Distribution: 9,661 Normal cases vs. 339 Failure cases (severe class imbalance).

5. Methodology & Domain Feature Engineering

To provide the classification algorithms with meaningful physical signals, four domain features were engineered from sensor telemetry based on the physical causes of machine failure:

1. Temp_Difference = Process Temperature [K] - Air Temperature [K]

Rationale: Heat Dissipation Failure (HDF) is directly caused when heat from machining cannot adequately transfer into the surrounding environment at lower rotational speeds.

2. Power_kW = (Torque [Nm] × Rotational Speed [rpm] × 2π / 60) / 1000

Rationale: Power Failure (PWF) occurs when the mechanical power output falls outside safe operational bounds (< 3.5 kW or > 9.0 kW).

3. Overstrain_Index = Tool Wear [min] × Torque [Nm]

Rationale: Overstrain Failure (OSF) occurs when high cutting torque is exerted on an already worn cutting blade.

4. Torque_Speed_Ratio = Torque [Nm] / Rotational Speed [rpm]

Rationale: Detects low-speed high-drag mechanical stalls.

6. Results & Model Comparison

Models were evaluated using 5-Fold Stratified Cross-Validation on the training set and tested on an independent hold-out test set (2,000 samples: 1,932 Normal, 68 Failures).

Performance Metric Logistic Regression (Balanced) Random Forest Classifier (Selected)
Accuracy 86.10% 98.05%
Recall / Sensitivity (TPR) 88.24% (60/68 caught) 89.71% (61/68 caught)
Precision (PPV) 18.18% 65.59%
Specificity (TNR) 86.02% 98.34%
F1-Score 0.3015 0.7578 (5-Fold CV: 0.7659)
ROC-AUC Score 0.9385 0.9869 (5-Fold CV: 0.9815)
PR-AUC (Average Precision) 0.4183 0.8574
False Positive Rate (FPR) 13.98% (270 false alarms) 1.66% (Only 32 false alarms)
False Negative Rate (FNR) 11.76% (8 missed) 10.29% (7 missed)

Model Selection Rationale: The Random Forest Classifier was chosen as the champion model. It detects 89.71% of all critical failures while reducing false alarms from 270 down to 32. The close agreement between 5-fold cross-validation F1 (0.7659) and test F1 (0.7578) demonstrates no overfitting or underfitting.

8. Web Application Architecture

The application features a single-screen responsive dashboard built with Flask and vanilla HTML5/CSS/JavaScript:

  • Interactive Telemetry Input: Real-time input controls with physical parameter validation.
  • Instant Scenario Presets: 1-click loading for Normal Run, Overstrain Risk, Thermal Dissipation Risk, and Power Overload.
  • Continuous Risk Gauges: Visual meters for Overstrain Load, Tool Life Expended, Power Envelope Stress, and Thermal Stress.
  • Model Performance & Explainability: Live side-by-side metrics and human-readable diagnostic risk factors.

9. Conclusion & Future Improvements

The Predictive Maintenance AI project successfully demonstrates a technically sound, explainable machine learning system capable of predicting industrial machine failure before catastrophic breakdown occurs.

Future Improvements:

  • Direct integration with IoT telemetry pipelines via MQTT or OPC-UA.
  • Remaining Useful Life (RUL) regression modeling.
  • Multi-class failure mode classification (TWF, HDF, PWF, OSF).
  • Automated retraining loops triggered by factory maintenance logs.
